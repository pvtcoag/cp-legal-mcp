Overview

What It Is

CP Legal MCP is a production remote Model Context Protocol server built for Australian legal research. It gives Claude (and other MCP clients) access to 25 specialised legal research tools covering case law, legislation, entity intelligence, regulatory decisions, ASX data, and matter management.

⚖️
Legal Research
Search, retrieve and analyse Australian case law and legislation via AustLII. Powered by Isaacus Kanon AI for semantic reranking, extractive QA, enrichment, and summarisation.
🏢
Entity Intelligence
Look up companies and persons by ABN, ACN, or name using ASIC Connect and the Australian Business Register (ABR). Returns registration status, type, directors/officers, and GST info.
📋
Matter Tracking
Every tool call is tagged to a matter reference and stored in PostgreSQL. Full audit trail, per-matter billing, and a web UI at /matters for researchers and admins.
📡
Regulatory & Market Data
Search ASIC and ACCC regulatory decisions, and ASX market announcements. All via public data sources with retry logic and abuse-prevention rate limiting.
🔐
OAuth 2.0 + PKCE
Full OAuth 2.0 Authorization Code + PKCE flow. Supports Claude Web, ChatGPT, Cursor, mcp-remote, and any RFC 7591 dynamic registration client. Bearer token auth for direct API use.
👤
Admin Portal
Web-based admin panel at /admin for user management, spend cap configuration, precedent watchlist, billing export, and system health. Session-cookie auth, admin-flag gated.
Primary Use Case
Practitioners use Claude with this MCP server for NSW/QLD/Federal legal research — drafting research memos, checking limitation periods and filing deadlines, monitoring precedents, and looking up entities for advisory matters.

Request lifecycle

Per MCP POST /mcp
1. Cloudflare CDN → Railway TLS termination
2. Express rate limiter (60 req/min per IP pre-auth)
3. authMiddleware — verifies Bearer token (DB hash lookup, then env fallback)
4. Per-user rate limiter (60 req/min post-auth)
5. spendCapMiddleware — checks monthly spend vs per-user / global cap (DB)
6. requestContext.run({ user }) — async context propagation
7. createMcpHandler() — fresh McpServer + StreamableHTTPServerTransport per request
8. Tool handler executes → may call auslaw-mcp, Isaacus, ASIC/ABR, ASX
9. recordMatterQuery() — fire-and-forget insert into matter_queries
10. res.on('close') → transport.close() + server.close()

Stateless by design

Each MCP request creates a fresh McpServer + StreamableHTTPServerTransport with sessionIdGenerator: undefined. No session state, no shared mutable objects. Safe for concurrent users and horizontal scaling. auslaw-mcp client is also fresh per tool call.

Services & APIs

ServiceRoleAuth / AccessRate Limit / Notes
cp-legal-mcp
Railway service — public		 Main MCP server. Exposes 25 tools to Claude and other clients. Hosts web UI and OAuth endpoints. Outbound: Isaacus SDK key, ASIC (none), ABR GUID, auslaw-mcp (private network — no auth) 60 req/min per IP (pre-auth) + 60/min per user (post-auth)
auslaw-mcp
Railway service — private		 AustLII scraper MCP server. Provides 9 tools for case/legislation search, document fetch, citation validation, LawCite citator. No auth on private network. MCP_TRANSPORT=http, PORT=3000 AustLII: 10 req/min (token bucket). LawCite: 5 req/min. Timeout: 60 s
Isaacus Kanon API
isaacus.com		 Legal AI layer. Three models: Kanon 2 Enricher, Kanon Answer Extractor, Kanon Universal Classifier (reranking). ISAACUS_API_KEY — passed to new Isaacus({ apiKey }) SDK: isaacus@^0.13.0. In-memory rerank cache (5 min TTL, 100 entries). QA cache (200 entries, LRU).
AustLII
austlii.edu.au		 Australian Legal Information Institute. Full-text case law and legislation database. Free public access. No API key. Accessed via auslaw-mcp only. Rate limited by auslaw-mcp token bucket. Judgment text cached in PostgreSQL for 30 days.
LawCite
austlii.edu.au/cgi-bin/LawCite		 AustLII citator — finds cases that have cited a given citation. Used by find_citing_cases. No auth. HTML scraping with cheerio. Falls back to AustLII phrase search. 5 req/min rate limit in auslaw-mcp.
ASIC Connect
connectonline.asic.gov.au		 Company and person register. Used by lookup_entity for name/ACN/ABN searches and officer lookups. No auth required. Public registry. Up to 2 retry attempts on 429/5xx. 15 s timeout per request.
ABR (Australian Business Register)
abr.business.gov.au		 ABN lookup and entity details via ABR web services. More reliable than ASIC for ABN/ACN resolution. ABR_GUID env var — free registration at abr.business.gov.au/Tools/WebServices Graceful degradation — ASIC Connect used as fallback if GUID not configured.
PostgreSQL
Railway managed DB		 All persistent data: users, sessions, matter queries, judgment cache, login events, OAuth, watchlist, app config. DATABASE_URL — Railway injects automatically. Schema auto-migrated on startup via initDb(). Pool: max 10 connections. Graceful close on SIGTERM.
ip-api.com
ip-api.com		 IP geolocation for login audit events (city, region, country). Fire-and-forget, non-blocking. No key required. Free tier. ~45 req/min limit. In-memory cache. 3 s timeout. Private/loopback IPs skipped.
Cloudflare DNS and CDN. CNAME api.example.com → Railway public URL. Cloudflare DNS console. No code integration. Railway trust proxy: 1 set. Real client IP read from leftmost X-Forwarded-For.

Authentication & Access Control

🔑
Bearer Token (MCP)
All /mcp requests require Authorization: Bearer <token>. Token verified against hashed value in PostgreSQL users table, then falls back to MCP_AUTH_TOKENS env var.
🔐
OAuth 2.0 + PKCE (Claude / ChatGPT)
Claude Web and ChatGPT use OAuth Authorization Code + PKCE (S256). Static client pre-registered via OAUTH_CLIENT_ID. Dynamic registration via /oauth/register for mcp-remote and Cursor.
🍪
Session Cookie (Web UI)
HMAC-SHA256 signed cookie cvn_matters. 8-hour TTL. Contains username, admin flag, session version, expiry, and signature. HttpOnly, Secure, SameSite=Strict.

Admin access

Admin access to the web UI is controlled by the is_admin flag in the users table (set via /admin/users/:username/toggle-admin) and the ADMIN_USERS env var (comma-separated, applies to env-only users). Admin flag is baked into the session cookie and verified on every admin request without a DB query.

Recovery access

Set RECOVERY_TOKEN (32+ chars) in Railway env vars. Log into the web UI with username recovery and this token as the password. Grants full admin access. Remove the env var after use.

Spend caps

Per-user cap
Set via /admin/users/:username → Spend Cap form. Stored in users.spend_cap_monthly_usd. Takes precedence over the global default. Resets monthly (AEST).
Global default cap
Set via /admin/config → spend_cap_monthly_per_user_usd. Applied to users without a per-user cap. Alert threshold at spend_cap_alert_threshold_pct% (default 80%).
Billing exports
Per-matter CSV: /matters/:ref/export.csv — download from the matter detail page.
Global CSV (admin): /admin/billing-export.csv — all matters, all users. Supports optional ?from=YYYY-MM-DD&to=YYYY-MM-DD query params.

Deployment

Railway setup

railway.toml (cp-legal-mcp)
[build]
builder = "DOCKERFILE"
dockerfilePath = "Dockerfile"

[deploy]
healthcheckPath = "/health"
healthcheckTimeout = 30
restartPolicyType = "ON_FAILURE"
restartPolicyMaxRetries = 3

Railway gates new deployments on the /health endpoint — returns 503 if DB is unreachable, keeping the old deployment live. 10-second SIGTERM force-exit guard prevents hanging on idle keep-alive connections.

Cloudflare DNS

DNS record
Type:    CNAME
Name:    api
Target:  [Railway public URL of cp-legal-mcp]
Proxy:   Proxied (orange cloud)

Railway sets app.set('trust proxy', 1) to read the real client IP from X-Forwarded-For. The custom clientIp(req) helper reads the leftmost IP from the header (real client, not proxy).

Node.js version

Node 22 — required
Both Dockerfiles use FROM node:22-alpine. Node.js 20 reaches end-of-life 30 April 2026. Do not downgrade. engines: "node": ">=22.0.0" in both package.json files.

Operations

SOPs & Runbooks

SOP 1 — Add a new user

1. Navigate to /admin/users/new
2. Enter username (lowercase, alphanumeric + hyphens)
3. Click "Create user"
4. Copy the token shown — it is displayed ONCE and cannot be recovered
5. Send the token to the user via a secure channel (not email)
6. User connects their MCP client with:
   - URL: https://api.example.com/mcp
   - Token: paste as password / bearer token
   - Claude Web: add as remote MCP server → OAuth flow handles auth automatically

SOP 2 — Rotate a compromised token

1. Navigate to /admin/users/:username
2. Click "Rotate token"
3. New token is displayed once — save immediately
4. Send new token to user via secure channel
5. All existing MCP sessions using the old token are immediately rejected
6. User must re-authenticate Claude Web / Cursor / other clients with the new token

SOP 3 — Force-log a user out of the web UI

1. Navigate to /admin/users/:username
2. Click "Force logout all sessions"
3. This increments the user's session_version in the DB
4. All existing cvn_matters session cookies for that user are immediately invalid
5. User will be redirected to /matters/login on their next page load
6. Login event logged with event_type = 'force_logout'

SOP 4 — Set spend cap for a user

1. Navigate to /admin/users/:username
2. Find the "Spend Cap" section
3. Enter USD amount (e.g. 50 for $50/month) — leave blank to use global default
4. Click "Set cap"
5. Dashboard at /matters/dashboard will show a spend progress bar
6. When cap is reached, tool calls return HTTP 429 with error: spend_cap_exceeded
7. To remove individual cap: clear the field and save → falls back to global default

SOP 5 — Set global spend cap

1. Navigate to /admin/config
2. Find spend_cap_monthly_per_user_usd → set global default in USD
3. Find spend_cap_alert_threshold_pct → set alert threshold (default 80%)
4. Find spend_cap_monthly_global_usd → optional hard cap across ALL users combined
5. Changes apply immediately — no restart required

SOP 6 — Recover admin access (locked out)

1. In Railway → cp-legal-mcp service → Variables
2. Add: RECOVERY_TOKEN = [generate 40+ char random string, e.g. via openssl rand -base64 32]
3. Save (triggers redeploy)
4. After redeploy, go to https://api.example.com/matters/login
5. Username: recovery    Password: [the RECOVERY_TOKEN value]
6. You now have full admin access
7. Create/fix your real admin account from /admin/users
8. IMPORTANT: Remove RECOVERY_TOKEN env var from Railway immediately after
9. Save (triggers redeploy to clear the recovery token)

SOP 7 — auslaw-mcp is unreachable

Diagnosis:
  curl https://api.example.com/health/auslaw
  Check Railway logs for auslaw-mcp service

Common causes:
  A) auslaw-mcp service crashed → restart from Railway dashboard
  B) AUSLAW_BASE_URL is wrong → verify it uses Railway private domain, not public URL
     Correct format: http://[service-name].railway.internal:3000
  C) auslaw-mcp is not in same Railway project → must be co-located for private networking

Impact:
  Tools that call auslaw-mcp return: { error: 'upstream_unavailable' }
  These tools are affected: research_cases, research_legislation, get_judgment,
    ask_judgment, enrich_judgment, summarise_judgment, find_citing_cases,
    find_related_cases, compare_cases, search_by_citation, format_citation, get_legislation

Tools NOT affected (no auslaw dependency):
  lookup_entity, lookup_entities_bulk, search_regulatory_decisions,
  search_asx_announcements, check_limitation_period, check_filing_deadline,
  get_matter_history, build_chronology, draft_research_memo, monitor_precedents

SOP 8 — Monitor precedent watchlist

Via Claude (MCP tool):
  monitor_precedents(action: "list")              — see all watched citations
  monitor_precedents(action: "add", citation: "[2024] HCA 1", label: "Smith v Jones")
  monitor_precedents(action: "check")             — scan all for new citing cases
  monitor_precedents(action: "remove", citation: "[2024] HCA 1")

Via Admin UI:
  /admin/watchlist — add/remove citations, see last-check counts

SOP 9 — Export billing data

Per-matter CSV:
  /matters/:ref → click "Download CSV" button
  OR: GET /matters/:ref/export.csv

Global billing export (admin):
  /admin → Matters section → "Export all billing (CSV)"
  OR: GET /admin/billing-export.csv
  With date filter: GET /admin/billing-export.csv?from=2024-01-01&to=2024-12-31

CSV format: Matter Ref, Display Name, Status, First Activity, Last Activity,
            Queries, Tokens, Cost (USD), Cost (AUD)
Includes TOTAL summary row at bottom.

SOP 10 — Purge judgment cache

Normal operation: judgments cached 30 days in judgment_cache table.
Cache hits are logged at DEBUG level: "judgment cache hit".

Purge expired entries:
  /admin/data → "Purge expired cache" → removes entries older than 30 days

Purge all:
  /admin/data → "Purge all judgment cache" → clears entire cache
  Next fetch of any cached judgment will re-fetch from AustLII

When to purge: if AustLII updated a document and you need the fresh version.
